# Matched Betting Personal

Personal webapp MVP for matched-betting analysis.

## Current scope
- Dashboard
- Opportunity scanner with mock opportunities
- Back/Lay calculator
- Operation tracking UI
- Bankroll summary
- Betfair integration placeholder (no real betting execution)
- Responsive dark UI

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Important
This MVP does not place real bets. Betfair credentials are intentionally not implemented yet.
The next phase is to connect official Betfair market data and validate all calculations against live/delayed data before considering any execution feature.
